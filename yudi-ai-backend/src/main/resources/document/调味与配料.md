# 调味与配料知识库

## 一、调味概论
调味是烹饪的核心之一，通过合理搭配调味料，平衡“酸、甜、苦、辣、咸、鲜、香”七味，达到色香味俱全的效果。

### 调味的五大目的
1. **去腥除膻**：如料酒、姜、葱、醋；
2. **提鲜增香**：如味精、鸡精、蚝油；
3. **调和口味**：如糖与醋、酱油与盐；
4. **着色增亮**：如老抽、糖色；
5. **延长保存**：如盐腌、酱渍。

| 调味料 | 类型 | 主要作用 | 常用菜式 |
|----------|----------|-----------|------------|
| 盐 | 咸味 | 提鲜、杀菌 | 几乎所有菜式 |
| 酱油（生抽） | 鲜咸 | 提鲜、提色 | 炒菜、凉拌 |
| 酱油（老抽） | 着色 | 上色、提香 | 红烧、卤菜 |
| 糖 | 甜味 | 调和酸咸、上色 | 红烧、糖醋 |
| 醋 | 酸味 | 去腥、解腻 | 糖醋、凉拌 |
| 味精/鸡精 | 鲜味 | 增鲜 | 炒菜、汤类 |
| 辣椒 | 辣味 | 刺激味觉 | 川菜、湘菜 |
| 花椒 | 麻味 | 香麻提味 | 麻辣系列 |
| 料酒 | 发酵酒 | 去腥提香 | 红烧、蒸鱼 |
| 蚝油 | 复合酱料 | 提鲜、上色 | 烩菜、炒牛肉 |
| 豆瓣酱 | 发酵酱料 | 辣香、咸鲜 | 回锅肉、鱼香 |

| 香油 | 油脂 | 提香、收尾 | 凉拌菜、汤类 |

| 花雕酒 | 中式黄酒 | 去腥、增香 | 东坡肉、醉鸡 |

## 三、调味规律与搭配
### 1. 五味平衡原则
| 主味 | 配合调味 | 常见菜例 |
|-------|-------------|-----------|
| 咸味 | 酱油、盐 | 红烧、清蒸 |
| 甜味 | 糖、番茄 | 糖醋排骨、西红柿炒蛋 |
| 酸味 | 醋、柠檬汁 | 鱼香、糖醋、凉拌 |
| 辣味 | 辣椒、花椒 | 川菜、湘菜 |
| 鲜味 | 味精、蚝油 | 炒菜、烩菜 |

### 2. 调味配比经验公式
- 糖醋比例：**糖 2：醋 1**
- 红烧比例：**生抽 2：老抽 1：糖 2**
- 鱼香比例：**生抽 2：糖 2：醋 1：淀粉水 1**

## 四、区域风味调料差异
| 菜系 | 代表调味 | 风味特点 |
|------|-------------|-------------|
| 川菜 | 花椒、豆瓣酱、泡椒 | 麻辣鲜香 |
| 湘菜 | 小米辣、剁椒、腊味 | 香辣重口 |
| 粤菜 | 蚝油、蒸鱼豉油、姜葱 | 清淡鲜美 |
| 鲁菜 | 葱姜蒜、酱油、糖色 | 酱香浓郁 |
| 苏菜 | 糖、酒、汤汁 | 甜鲜软嫩 |
| 闽菜 | 沙茶酱、红糟 | 酱香微甜 |
| 浙菜 | 黄酒、鲜酱油 | 清爽甘鲜 |

## 五、特殊调味技巧
- **先甜后咸**：糖先入可使酱油提香；
- **先盐后酱油**：保持菜色亮丽；
- **勾芡提味**：淀粉水收尾使汁浓味厚；
- **香油收尾**：增加余香层次；
- **冷菜多用醋与芝麻酱**：提香、解腻。

---

## 六、常见调味错误
- 盐加得太早导致肉质变柴；
- 酱油炒糊产生苦味；
- 酸味与辣味比例失衡导致刺口；
- 香料使用过量掩盖主料风味。
