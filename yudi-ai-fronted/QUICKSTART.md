# 快速启动指南

## 安装依赖

```bash
cd yudi-ai-fronted
npm install
```

## 启动开发服务器

```bash
npm run dev
```

项目将在 `http://localhost:7000` 启动。

## 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

## 注意事项

1. 确保后端服务已启动在 `http://localhost:9000`
2. 首次使用需要注册账号（邮箱验证码登录）
3. 登录后会自动创建第一个会话
4. 支持流式输出（打字机效果），如果流式失败会自动降级到非流式接口

## 功能说明

- **登录/注册**：使用邮箱验证码方式
- **会话管理**：支持多个会话，每个会话独立管理
- **流式聊天**：优先使用SSE流式接口，自动降级到非流式
- **深度思考**：可通过开关切换深度思考模式
- **响应式布局**：小屏设备自动折叠左侧栏
- **Markdown渲染**：AI回复支持Markdown格式渲染
